USB Linker Advance (AN2131) — Memory Viewer / Get Cart Info / Dump ROM。プロトコルは GBA-Memviewer-ULA / ula_driver_libusb に準拠。Chrome / Edge 専用。

このブラウザはWebUSB非対応です。Chrome / Edge で開いてください。

接続

EZ-USBファーム gba_boot.bix
GBA側ファーム fwlib20030312.bin
（ブラウザに保存され次回以降は不要）
① 未初期化のULA（ファーム未ロード）を選択 → 数秒後に再列挙 → ② でOnline側のデバイスを選択し、GBAを START+SELECT を押しながら電源ON。
※ Windowsでは Zadig で両方のデバイスにWinUSBドライバが必要です。
